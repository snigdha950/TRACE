> TRACE is a research prototype for AI-driven spatio-temporal detection and tracking of extreme-weather anomalies in medium-range forecasts. The deployed interface demonstrates the frozen BULBUL extreme-wind footprint evidence, forecast-lead views, Stage-1 → Stage-2 handoff, provenance checks, temporal-tracking evidence, and REST API.

### Quick Demo

1. Open the **Live Dashboard**.
2. Switch between **+72 h**, **+96 h**, and **+120 h** forecast leads.
3. Review the detected geographic footprint, anomaly core, severity tier, seed agreement, EFI/SOT, wind evidence, and member support.
4. Scroll down to view the Stage-2 route, evidence-integrity status, temporal-tracking evidence, safety boundaries, and implemented API endpoints.
5. Open the **API Documentation** link to inspect and test the backend endpoints.

**Important:** TRACE is a research prototype and does not issue official IMD/NCMRWF weather warnings.
